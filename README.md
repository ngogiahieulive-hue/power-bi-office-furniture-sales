# Office Furniture Sales Dashboard

## Project Overview
This Power BI project analyzes office furniture sales performance across customers, products, order status, and shipping methods.

The dashboard is designed to provide a clear overview of business performance and support data-driven decision-making through interactive visualizations and KPIs.

## Tools & Technologies
- Power BI
- Power Query
- DAX
- Data Modeling

## Dashboard Features
- Revenue and order performance monitoring
- Monthly and daily sales trend analysis
- Product performance analysis
- Customer analysis
- Order status tracking
- Shipping method analysis
- Interactive slicers and KPI cards

## Skills Demonstrated
- Power BI dashboard development
- Data transformation using Power Query
- DAX measures and KPI development
- Data modeling
- Business performance analysis
- Data visualization and insight generation
